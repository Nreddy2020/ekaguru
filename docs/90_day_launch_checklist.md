# Ekaguru: 90-Day Launch Checklist

## Month 1: Closed Pilot (Days 1-30)

### Week 1: Setup & Recruitment
- [ ] Finalize MVP feature set (core subjects only)
- [ ] Set up analytics (Mixpanel/Amplitude)
- [ ] Create onboarding flow
- [ ] Recruit 50-100 pilot families (referrals, parent groups)
- [ ] Set up feedback channels (WhatsApp group, weekly calls)

### Week 2-3: Pilot Launch
- [ ] Onboard first 25 families
- [ ] Daily monitoring & bug fixes
- [ ] Collect initial feedback
- [ ] Iterate on UX/voice tone
- [ ] Document common issues

### Week 4: Analysis & Iteration
- [ ] Analyze fear index trends
- [ ] Collect testimonials (video + text)
- [ ] Identify top 3 UX improvements
- [ ] Plan Month 2 features
- [ ] Create case study (1-2 families)

**Success Metrics**:
- [ ] 70%+ parents report "child is less afraid"
- [ ] 60%+ weekly active users
- [ ] <5 critical bugs

---

## Month 2: Open Beta (Days 31-60)

### Week 5: Beta Preparation
- [ ] Build referral system (invite codes)
- [ ] Launch parent dashboard
- [ ] Set up email automation (weekly insights)
- [ ] Create onboarding videos
- [ ] Prepare marketing materials

### Week 6-7: Beta Launch
- [ ] Open to 500-1,000 users (referral-only)
- [ ] Launch WhatsApp community
- [ ] Weekly parent webinars
- [ ] Collect more testimonials
- [ ] Monitor retention metrics

### Week 8: PMF Validation
- [ ] Analyze retention (30-day cohort)
- [ ] Survey users (NPS score)
- [ ] Identify power users
- [ ] Document success stories
- [ ] Refine pricing strategy

**Success Metrics**:
- [ ] 40%+ retention after 30 days
- [ ] NPS > 50
- [ ] 20+ strong testimonials

---

## Month 3: Paid Launch (Days 61-90)

### Week 9: Payment Setup
- [ ] Integrate payment gateway (Razorpay/Stripe)
- [ ] Set up subscription management
- [ ] Create pricing page
- [ ] Build cancellation flow
- [ ] Test payment flows

### Week 10-11: Public Launch
- [ ] Soft launch (limited marketing)
- [ ] Launch landing page
- [ ] Start content marketing (YouTube, blog)
- [ ] Reach out to schools (demos)
- [ ] Monitor conversion funnel

### Week 12: Optimization
- [ ] Analyze conversion rates
- [ ] A/B test pricing
- [ ] Optimize onboarding
- [ ] Set up customer support
- [ ] Plan Month 4-6 roadmap

**Success Metrics**:
- [ ] 1,000+ paying users
- [ ] ₹5L+ MRR
- [ ] <20% churn
- [ ] 5-10 school partnerships (in pipeline)

---

## Ongoing (Throughout 90 Days)

### Product
- [ ] Weekly bug fixes
- [ ] Bi-weekly feature releases
- [ ] Daily monitoring (uptime, errors)
- [ ] User feedback integration

### Marketing
- [ ] 2-3 YouTube videos/month
- [ ] 1-2 blog posts/week
- [ ] Daily social media (LinkedIn, Twitter)
- [ ] Weekly parent webinar

### Sales
- [ ] 5-10 school demos/month
- [ ] Follow up with leads
- [ ] Create sales collateral
- [ ] Build case studies

### Operations
- [ ] Weekly team sync
- [ ] Monthly investor update (if applicable)
- [ ] Financial tracking
- [ ] Legal compliance (data privacy)

---

## Key Milestones

- [ ] **Day 30**: 100 pilot users, first testimonials
- [ ] **Day 60**: 500 beta users, PMF signals
- [ ] **Day 90**: 1,000 paying users, ₹5L MRR

---

## Resources Needed

### Team (Minimum)
- 1 Product Manager
- 2 Full-stack Engineers
- 1 Pedagogy Expert
- 1 Marketing/Community Manager
- 1 Customer Support

### Budget (Month 1-3)
- Infrastructure: ₹50K/month
- Marketing: ₹1L/month
- Operations: ₹50K/month
- **Total**: ₹2L/month (₹6L for 90 days)

---

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Low adoption | Heavy parent education, testimonials |
| High churn | Weekly insights, visible progress |
| Technical issues | Daily monitoring, fast bug fixes |
| Competition | Category creation, pedagogy moat |

---

**Remember**: This is a marathon, not a sprint. Focus on quality over quantity.
