## SLIDE 7: Product Demo Snapshot

### Example: Fractions (Grade 5)

**Problem**: Child says "1/4 is bigger because 4 is bigger"

**Our System**:
1. **Detects** misconception ("denominator as size")
2. **Destroys** wrong mental model safely (pizza analogy)
3. **Rebuilds** understanding using real-world sharing
4. **Confirms** mastery via teach-back + transfer

**Result**: Child can explain AND apply fractions in new contexts

**This is learning engineering, not Q&A.**
