# Ekaguru Pilot Program: Parent & Student Guide

**Welcome to the Ekaguru Pilot!** 🚀  
Thank you for joining us on this journey to revolutionize personalized learning. This guide will help you set up and start using the Ekaguru platform.

---

## 📋 Prerequisites

1.  **Computer/Laptop**: A Windows, Mac, or Linux computer.
    *   *Note: Mobile/Tablet support is coming in Phase 6.*
2.  **Browser**: Google Chrome or Microsoft Edge (Required for Voice Features).
3.  **Headset**: A microphone is required for the student to talk to the Avatar.

---

## 🚀 Getting Started

### Step 1: Login (Parent)
1.  Navigate to the **Parent Dashboard** url provided in your invitation email.
2.  You will see the **Analytics Dashboard**. This is your command center.
    *   **Fear Index**: Monitors your child's confidence.
    *   **Mastery Score**: Tracks academic progress.
    *   **Learning Velocity**: Shows how quickly they are grasping new concepts.

### Step 2: Student Session
1.  Click the **"Student Mode"** button in the top right corner.
2.  **Allow Microphone Access** when prompted by the browser.
3.  The **Ekaguru Avatar** will appear.

### Step 3: The Learning Loop
1.  **Greeting**: The avatar will introduce itself.
2.  **Interaction**: The student can speak naturally.
    *   *Try saying: "I want to learn about fractions."*
    *   *Try saying: "This is hard, I'm stuck."*
3.  **Feedback**:
    *   If the student struggles, the avatar becomes **Compassionate**.
    *   If the student succeeds, the avatar **Celebrates**.

---

## 🆘 Troubleshooting

**"The Avatar isn't listening!"**
*   Check if your microphone is muted.
*   Ensure you clicked "Allow" on the browser permission popup.
*   Refresh the page.

**"No sound?"**
*   Check your computer volume.
*   The Avatar uses text-to-speech; ensure your browser tab is not muted.
