<product_requirements>
The user initially requested a Virtual Tutor Application for children and students, emphasizing human-like interaction. Key features evolved to include:
1.  **AI-powered Tutoring:** Utilizing Emergent LLM key (OpenAI/Claude) for intelligent responses, with adaptive learning (quiz vs. explanation modes).
2.  **Interactive Learning Flow:** Structured learning by chapters, with the ability for students to choose chapters, ask for deeper explanations of words/concepts, and take quizzes.
3.  **Content Upload:** Initially text files, later expanded to accept PDFs, images (with OCR for text extraction), and Word documents for processing.
4.  **Visual Learning Experience:** Integration of images from uploaded content, interactive explanations with visual aids, and potentially generating new clarifying images.
5.  **Avatar Interaction:** An engaging tutor avatar (initially 3D, reverted to 2D animated due to technical issues), with a motherly female voice, actively guiding students.
6.  **Student Management:** Student profile creation and progress tracking (topics, completion percentage).
7.  **Textbook Management:** Uploading, processing, and later, the ability for students to delete uploaded books or images.
</product_requirements>

<key_technical_concepts>
-   **Backend:** FastAPI, PostgreSQL with pgvector (for vector similarity search), Emergent LLM Key (integrating OpenAI/Claude), PyPDF2, Pillow, pytesseract, python-docx, opencv-python-headless (for file processing and OCR).
-   **Frontend:** React.js, Tailwind CSS, React Three Fiber (initially for 3D avatar), Zustand (state management).
-   **Infrastructure:** Supervisor (for service management), MongoDB (initial database, later replaced by PostgreSQL).
</key_technical_concepts>
